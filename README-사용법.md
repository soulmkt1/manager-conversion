# 실장별 DB 전환율 대시보드 — 사용법 (이 PC = 서버)

> 최종 수정: 2026-07-14

이 PC 안에 데이터를 저장하고, 웹 주소로 접속해 쓰는 방식입니다.
**외부 계정(구글/Supabase/Vercel 등) 가입이 전혀 필요 없습니다.**

## 실행 방법

1. 이 폴더의 **`시작하기.bat`** 파일을 더블클릭합니다.
   - 검은 창이 뜨고 잠시 후 아래처럼 주소가 표시됩니다.
   ```
   이 PC에서:      http://localhost:8787
   같은 네트워크:  http://192.168.0.10:8787
   공용 비밀번호:  topline1234
   ```
2. 이 PC에서는 웹브라우저 주소창에 `http://localhost:8787` 입력.
3. **같은 와이파이/네트워크에 있는 다른 PC·노트북**에서는
   위에 표시된 `http://192.168.0.xx:8787` 주소로 접속하면 같은 데이터를 함께 봅니다.
4. 로그인 화면에서 **공용 비밀번호**를 입력하면 됩니다.

> 이 검은 창(서버)이 **켜져 있는 동안만** 다른 사람이 접속할 수 있습니다.
> 컴퓨터를 꺼도 데이터는 사라지지 않습니다. 다시 `시작하기.bat` 을 실행하면 그대로 있습니다.

## 다른 장소(외부)에서 접속하기 — 외부공유.bat

같은 사무실이 아니라 **집·다른 지점·휴대폰(LTE)** 에서도 접속하려면:

1. **`외부공유.bat`** 을 더블클릭합니다. (서버가 자동으로 함께 켜집니다)
2. 잠시 뒤 창에 이런 주소가 나옵니다:
   ```
   https://xxxx-xxxx-xxxx.trycloudflare.com
   ```
3. 이 **https 주소**를 외부에 있는 사람에게 보내면, 그 사람도 인터넷만 되면 접속됩니다.
   (로그인 화면에서 공용 비밀번호 입력)

주의사항:
- 이 창(터널)과 서버가 **켜져 있는 동안만** 외부 접속이 됩니다. 창을 닫으면 끊깁니다.
- **주소는 켤 때마다 새로 바뀝니다.** 재시작하면 새 주소를 다시 공유해야 합니다.
  (항상 같은 주소가 필요하면 알려주세요 — 고정 주소 설정을 도와드립니다.)
- ⚠️ **외부 공개 시에는 반드시 공용 비밀번호를 강한 것으로 바꾸세요** (아래 참고).
  환자 이름 등 민감정보가 인터넷을 통해 오가므로 `topline1234` 같은 기본값은 위험합니다.

## 비밀번호 바꾸기

`server\config.json` 파일을 메모장으로 열어 `password` 값을 바꾸고 저장한 뒤,
서버 창을 닫았다가 다시 `시작하기.bat` 을 실행하세요.
```json
{ "password": "원하는비밀번호", "port": 8787 }
```

## 데이터는 어디에 저장되나요?

`server\data\app.db` 파일 하나에 모두 저장됩니다.
이 파일을 복사해두면 **백업**이 됩니다. (USB 등에 복사)

## 사용법 (화면)

- **입력 탭**: 한 주 보고서 텍스트를 통째로 붙여넣고 **분석** → 표에서 실장·채널·분류·중복을
  확인/수정 → **저장**. 틀린 곳은 표 안에서 바로 고칠 수 있습니다.
- **대쉬보드 탭**: 실장별/채널별 전환율·취소, 날짜별 추이, 결과 분포.
  - 우측 상단에서 **일별/주차별/월별** 기간을 선택하면 그 기간 데이터만 보입니다(주차는 실제 달력 기준).
  - 우측 상단 **⬇ PDF 다운로드** 버튼으로 현재 화면을 PDF 파일로 저장합니다.
- **목록 탭**: 저장된 공급/티켓팅 검색·수정·삭제, 기간 필터, CSV(엑셀) 내보내기.
  - 값을 고치면 자동 저장됩니다. 삭제해도 바로 사라지지 않고 **관리 > 삭제 데이터**에서 복원할 수 있습니다.
- **중복 탭**: 같은 고객이 여러 실장에게 잡힌 경우 자동으로 모아 보여줍니다. 남길 것만 두고 삭제.
- **일본상담 탭**: 일본 환자 상담 내역(부위·비용·예약금).
- **관리 탭(⚙️)**: 서브메뉴 2개.
  - **채널 매핑**: 유입 채널 매핑(`지`→`지오`, `플`→`플러스친구` 등)과 결과분류 키워드를 추가/수정.
    - **설정 저장** = 다음 입력부터 적용. **기존 공급 데이터에 다시 적용** = 이미 저장된 데이터도 새 규칙으로 한 번에 정리.
  - **삭제 데이터**: 목록·수정에서 삭제한 공급/티켓팅이 모입니다. **복원** 버튼으로 되돌립니다.

> 참고: `server\data\app.db.bak` 은 대량 정리 전 자동 백업본입니다. 문제가 없으면 지워도 됩니다.

## 다른 PC에서 접속이 안 될 때

- 같은 공유기(와이파이)에 연결되어 있는지 확인하세요.
- 처음 실행 시 Windows 방화벽이 "액세스 허용"을 물으면 **허용**을 눌러주세요.
- 서버 PC의 주소는 `시작하기.bat` 창에 표시된 `192.168.x.x` 주소를 그대로 사용하세요.
